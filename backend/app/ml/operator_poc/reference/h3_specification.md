# H3 일정·활동 운영 최적화 — FINAL v2

## 1. 목적

H3는 동호회 운영자가 활동 일정을 결정할 때
회원들의 실제 가능시간, 장소 이용 가능 여부, 이동조건,
참여 가능 인원 등을 종합하여 운영 가능성이 높은
Top-3 일정 후보를 제안하는 엔진이다.

공식 조사데이터 기반 Prior는 실제 참석확률 예측값이 아니라
Cold Start 단계에서 활용하는 보조 정보이다.


## 2. 공식 검증 지원종목

- 축구·풋살
- 농구
- 배구
- 탁구
- 테니스

지원종목은 'H3 엔진을 사용할 수 있는 종목'과
'종목별 Prior까지 검증된 종목'을 구분한다.

미검증 종목도 H3 운영엔진 자체는 사용할 수 있으나,
검증되지 않은 종목 전용 Prior는 사용하지 않고
Global Prior로 fallback한다.


## 3. 기존 4종목 Official Prior

축구·풋살 / 농구 / 배구 / 탁구는
기존 H3 Context + Sport Prior를 유지한다.

실제 모델 입력 Feature:

1. 응답자_지역_광역
2. 주운동_참여빈도
3. 현재동호회_주종목

이 모델은 일정 참석확률을 의미하지 않으며,
공식 생활체육조사에서 관측된 일정 패턴을
Cold Start 후보 정렬에 활용한다.


## 4. 테니스 예외정책

테니스 유효 일정 표본은 321명이다.

Rolling Temporal Validation 결과:

- Global Top-3: 51.25%
- Tennis Sport Prior Top-3: 52.50%
- 개선폭: +1.25%p
- 평가연도: 우세 2 / 동일 4 / 열세 0

따라서 테니스 Sport Prior는
약한 양의 효과만 확인되었으므로
강한 점수요소가 아니라 Tie-break 용도로 사용한다.

반면:

- Region + Frequency: 46.25% (-5.00%p)
- Region + Frequency + Sport: 45.83% (-5.42%p)

로 성능이 감소했으므로 테니스에는
지역 및 활동빈도 Context Prior를 적용하지 않는다.


## 5. 일정 슬롯 표준

모든 일정은 다음 Canonical Format으로 처리한다.

요일 | 시간대

예:
- 평일 | 저녁(18~22시)
- 휴일 | 오전(8~12시)

기존 '+' 구분자와 '|' 구분자는 동일 일정으로 정규화한다.


## 6. 최종 서비스 우선순위

H3는 다음 순서로 후보를 평가한다.

1. 회원 실제 가능 요일·시간
2. 장소 사용 가능 여부
3. 회원 이동 가능 범위
4. 참여 가능한 회원 수
5. 최소 참여인원 충족 여부
6. Official Prior
7. 부족인원 Guest fallback
8. 중복 없는 Top-3 일정 반환

Official Prior는 실제 운영조건보다 낮은 우선순위에 위치한다.


## 7. Ranking 원칙

최종 일정 정렬은 다음 우선순위를 따른다.

1. 최소 참여인원 충족 일정
2. 필요한 게스트 수가 적은 일정
3. 참여 가능 회원 수가 많은 일정
4. 참여 가능 비율이 높은 일정
5. Official Prior 순위
6. Official Prior Score

따라서 Prior가 높은 일정이라도
실제 참여 가능한 회원이 적으면
더 많은 회원이 참여 가능한 일정을 역전할 수 없다.


## 8. 장소 선택

동일 일정에 여러 장소가 존재하는 경우,
각 회원의 이동 가능 범위를 적용한 뒤
가장 많은 회원이 접근 가능한 장소를
해당 일정의 대표 Venue로 선택한다.


## 9. Guest fallback

최소 참여인원을 충족하지 못한 경우
동호회가 게스트 모집을 허용하면

필요 게스트 수 =
최소 참여인원 - 참여 가능 회원 수

를 계산하여 Guest fallback 후보로 유지한다.

게스트 모집을 허용하지 않는 경우
최소 참여인원 미달 일정은 추천 후보에서 제외할 수 있다.


## 10. 테니스 최종 정책

테니스의 서비스 흐름은 다음과 같다.

회원 실제 가능시간
→ 코트/장소 가능 여부
→ 이동조건
→ 참여 가능 인원
→ 최소 참여인원
→ Tennis Sport Prior Weak Tie-break
→ Guest fallback
→ Top-3

테니스 Prior는 일정의 주된 결정요인이 아니다.


## 11. 미검증 종목

배드민턴, 야구 등 아직 별도 시간순 검증을 하지 않은 종목은:

- 회원 직접 입력 기반 일정추천: 가능
- Venue / 이동거리 / 최소인원 적용: 가능
- 종목별 검증 Prior: 사용하지 않음
- Global Prior: fallback 용도로만 사용

추후 종목별 데이터 Audit 및 Rolling Validation을 통해
공식 지원종목으로 승격할 수 있다.


## 12. 현재 한계

현재 공식 조사데이터에는 실제 서비스의
schedule_vote, 일정 확정 이후 참석 여부,
추천 전후 참여율 변화 데이터가 존재하지 않는다.

따라서 현 단계 H3는
'실제 참석률을 예측하는 모델'이 아니라

공식데이터 Prior +
회원 직접 입력 +
운영 Hard Constraintt

를 결합한 Hybrid Schedule Recommendation Engine이다.


## 13. 향후 학습 방향

서비스 로그 축적 후 다음 Target을 구성할 수 있다.

- 일정 후보별 투표율
- 일정 확정 후 실제 참석률
- 추천 일정 대비 취소율
- Guest 모집 필요 여부
- 일정 추천 후 운영 성공 여부

이 데이터가 충분히 축적되면
현재 Rule/Prior 구조를 실제 참여확률 예측모델로
재학습 및 Calibration 할 수 있다.
